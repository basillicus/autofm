## How labeling works here

Labels are **not** inline in the telemetry. Each alarm in `alarms.csv` is an interval `[eventTime, clearTime]` on a specific `fdn`. A telemetry window for an entity is labeled by whether an alarm is active on that entity (or an ancestor in its fdn) within the forecast horizon. This makes it a genuine *fault prediction* task, not a lookup.
